营销服务 / 广告代理

依据：营销、广告、公共关系、传播、创意、投放

出海营销

依据：出海、跨境、全球主要市场、Meta、Google、TikTok
⚠ 地域要对齐 —— 出海业务的倍数锚在海外同业，不是 A 股同业

营销科技 / MarTech

依据：营销科技、数字营销、程序化、DSP、智能投放
⚠ 挂个「科技」名字但实质是代理的，倍数不该按 SaaS 给

企业服务 / to B 服务

依据：赋能、解决方案、智慧经营
⚠ to B 与 to C 的倍数能差一倍，筛选时商业模式要单独拎出来

净债务口径—租赁负债算不算债务 —— EV 和 EBITDA 口径要配套要你定
