# JEV 可用位置评估（TypeSafe AI · System One Models）

> 结论一句话：**JEV 不是"又一个更聪明的大模型"，它不能生成任何文字。**
> 它的形状恰好对上本工具里"要一个判定、不要一段话"的那些位置。
> 评估日期 2026-09-24。**所有性能数字均为厂商自报**（尚无大规模独立复现，DataCamp 明确标注）。

## 一、它是什么

TypeSafe AI 于 2026-09-15 发布的首个 **System One 模型**，自称"决策模型"。

| | 常规 LLM（DeepSeek / GPT / 本机 qwen 等） | **JEV** |
|---|---|---|
| 输入 | 文本 | 文本（程序状态） |
| 输出 | 一段**文字**，需解析、可能跑偏 | **结构化判定**：Choice（分类）/ Score（打分）/ Noul（是或否）+ **校准过的置信度** |
| 采样 | 逐 token 串行 | 单次并行 |
| 速度 | 3~329 秒 | 中位 **0.33 秒**（独立测试：比对比模型快约 3.6 倍） |
| 成本 | 输出比输入贵约 5 倍 | 输入 $0.042/百万 token，**输出不计费** |
| 幻觉 | 有 | **出不来**（只能从预先定义的答案集里选，厂商称 0% 结构错误率） |
| 短板 | — | **只给数，不给理由**；不能写任何正文 |

接口：`POST https://api.typesafe.ai/v1/systemone`，早期访问模型名为 `jev-latest`。
**当前状态：early access + waitlist，尚未开放常规接入。**

## 二、判定尺子

> **要的是"一个判定" → 它能用；要的是"一段话" → 它用不了。**

## 三、逐处评估（FreeAnalyst 现状）

目前模型在本工具里**只用在两处**：命令行问答 `ask`、质量门槛评测。其余判定全部由确定性代码完成。

| 位置 | 现状实现 | JEV 能不能用 | 说明 |
|---|---|---|---|
| 问答回答（`ask`） | 模型 | ✗ | 必须输出带 `[S1]` 出处的文字 |
| 估值报告正文 | 确定性代码 | ✗ | 报告是给人读的 |
| 质量门槛评测（5 道题） | 模型 | ✗ / 半 | 判分要求"引用 CIM 片段、访谈纪要"，它给不出引用 |
| 报表科目映射（标签 → 标准科目） | 规则 / 关键词 | **✓✓ 最合适** | 典型"模糊分类 + 置信度"；**金融业报表（保险/银行/券商）目前正因规则覆盖不到而失手** |
| 口径判定（合并 / 母公司、单位、期间） | 规则（`financials/meta.py`） | **✓✓** | 三选一，正是 Choice 的形状 |
| 来源类别判定（财报原文 / 推算 / 外部 / 需用户判断） | 规则 | **✓✓** | 四类标签目前靠规则，判定模型天然对口 |
| 材料完备性检查（有无审计报告 / 管理层报表 / 税表） | 规则 | **✓✓** | Noul（是/否 + 概率），且**不会瞎说有** |
| 幻觉闸门（回答里有无材料不支持的断言） | 人工/事后核对 | **✓✓** | 用它当裁判**比用大模型当裁判更可靠** —— 它自己不能编 |
| 跨文档冲突（访谈纪要 vs CIM 条款锁定状态） | 模型 | **✓✓** | 实测本机模型在这道题上普遍失手（5 道题里最难的一项） |

## 四、接它的三道硬约束

1. **不是 OpenAI 兼容接口** ✗ —— 不能在现有 15 家服务商那套里加一行，必须**单开适配器**；
   每个判定位要先写成 schema（可选答案集、打分口径）。
2. **托管 API = 材料离开本机** ✗ —— 必须走**按次授权 + 进审计**（`guard.CloudConsent` 那套），
   与云端模型同规矩，**绝不加全局开关**。
3. **它不给理由** ✗ —— 只能当**闸门 / 初判**，最终仍需人点头；用于受审计场景要靠
   **置信度阈值**兜底（低于阈值转人工），不能让一个没有解释的数单独定案。

## 五、下一步（拿到访问权之后）

1. 先把上面 6 个"判定位"写成 schema 草案（每个位置：可选答案集 + 触发阈值 + 落到审计里的字段）。
2. 单开 `llm/systemone.py` 适配器，复用 `guard` 的按次授权与审计，**不并入现有服务商清单**。
3. 用同一套质量门槛对照一次：**同一个判定位，JEV vs 现有规则 vs 本机模型**，
   谁错得少用谁 —— 而不是因为它新就用它。
