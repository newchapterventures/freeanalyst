# 投后指标

> 投前看的指标，和投后要盯的指标，必须是同一套。
> 否则你会在投前用一套话术，投后用另一套解释。

## 核心指标（不超过五个）

**为什么限制在五个**：能持续盯住的指标只有这么多。列二十个等于一个都不盯。

| # | 指标 | 精确定义 | 数据来源 | 上报频率 |
|---|---|---|---|---|
| 1 | | | | 月度 |
| 2 | | | | 月度 |
| 3 | | | | 季度 |
| 4 | | | | 季度 |
| 5 | | | | 季度 |

### 定义要精确到什么程度

示例（**照这个粒度写**）：

```
指标：期末经常性收入（ARR）
定义：截至期末仍处于服务期内、且客户已签署年度或以上合同的
      月度订阅金额 × 12。
      不含：一次性实施费、按月付费客户、已提出解约但未到期的客户。
口径变更：任何口径调整必须提前一个季度书面说明，且同时提供新旧口径两套数。
```

**模糊的定义会给留操作空间。** 你定义得越松，管理层报给你的数就越好看。

## 上报纪律

- 每月 10 日前提交上月数据
- 偏差超过黄灯，必须附一页说明，写清原因和纠偏动作
- 连续两期红灯，触发董事会层面讨论
