# 证据规则

> 这份文件决定 agent 在什么情况下可以下结论、什么情况下只能说"未提供"。
>
> **它是整套框架里最容易被忽略、但最重要的一份。**
> 因为一个会编数字的尽调助手，比没有助手更危险。

## 证据分级

| 级别 | 定义 | 能不能直接下结论 |
|---|---|---|
| **A 级** | 审计报告、银行流水、工商登记、已签署合同、税务申报 | ✅ 可以 |
| **B 级** | 公司管理报表、内部台账、访谈中可交叉验证的陈述 | ⚠️ 需交叉验证 |
| **C 级** | 管理层口径、BP 自述、未签署条款清单、行业传闻 | ❌ 只能形成假设 |
| **D 级** | 无来源的数字 | ❌ 禁止使用 |

**材料里写"管理层称"、"据公司介绍"、"预计"、"目标"的，一律按 C 级处理。**

## 硬规则

1. **禁止用常识补全。** 材料里没有的数字，输出"材料未提供"，不许推算。

2. **禁止跨口径合并。** 报表 EBITDA 和调整后 EBITDA 是两个数，不许平均、
   不许混用、不许拿一个去算另一个的倍数。

3. **数字原样引用。** 不许四舍五入、不许换算单位、不许改符号。
   加回项必须标明方向（是加回还是扣除）。

4. **每条结论必须有出处。** 格式：`[来源编号] 文件名#段落`。
   没有出处的结论直接删除。

5. **冲突必须报出。** 两份材料对同一件事说法不一致时，**明确指出冲突并
   列出两边原文**，不许选一个信、不许调和。

6. **主体不能搞混。** 回购义务人、担保人、实际控制人、公司——四个不同的
   法律主体。把个人义务说成公司压力，是致命的错误。

## 输出时的自检

在给出任何结论前，agent 应该能回答：

- [ ] 这条结论的依据在哪一份材料的哪一段？
- [ ] 这个数字是 A/B/C 哪一级证据？
- [ ] 有没有另一份材料说了不一样的话？
- [ ] 责任主体是公司还是个人？
- [ ] 我有没有把"未提供"悄悄换成了一个看起来合理的假设？

## "材料缺口"怎么写

问到的问题材料里没答案时，**不要写"材料未提供"四个字交差**。

要写成：

```
问题：2025 年质保赔付的成因是否已闭环？
材料缺口：
  - 缺质量分析报告（需向标的索取）
  - 缺客户方确认函（访谈中董事长称"回去找一下"）
  - 缺该批次后续订单数据
现有材料中的相关陈述：管理层访谈纪要 [S5]「董事长确认系单一客户批次问题，
已闭环」—— 属 C 级证据，待 A 级材料验证。
```

**缺口本身也是尽调成果。** 它告诉合伙人下一步该要什么材料。
