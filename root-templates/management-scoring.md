# 管理层评分量表

> 人是最重要的变量，也是最难量化的。
>
> **写法要求：每一档都要写"什么证据能支撑这一档"。**
> 不然评分会变成情绪打分。

## 打分维度

### 1. 操盘经验

| 档位 | 定义 | 什么证据能支撑 |
|---|---|---|
| 5 | 有一次从 0 到 1 亿以上收入的完整经历 | 工商变更 + 财务报表 + 可交叉验证的访谈 |
| 4 | 有一次从 0 到 3000 万以上收入的经历 | |
| 3 | 在中大型企业任过业务负责人 | 任职证明 |
| 2 | 有创业经历但未验证规模 | |
| 1 | 无操盘经验 | |

### 2. 行业认知

| 档位 | 定义 | 什么证据能支撑 |
|---|---|---|
| 5 | 能准确说出竞争对手的成本结构和客户决策链 | 访谈中给出可验证的具体数字 |
| 3 | 了解主要竞争者但停留在公开信息层面 | |
| 1 | 说不清主要对手 | |

### 3. 诚信

<!-- 这一栏权重最高，也最难。 -->

| 档位 | 定义 | 什么证据能支撑 |
|---|---|---|
| 5 | 主动披露对自己不利的信息 | 访谈中主动说出问题，且后来被印证 |
| 3 | 被问到才承认 | |
| 1 | 对已被材料证实的问题仍否认 | 材料与访谈直接冲突 |

> **重要**：访谈中主动披露不利信息，是最强的正面信号，权重要给够。
> 反过来，被材料打脸还否认的，不投——不管数字多好看。

| 财务负责人 | | |
