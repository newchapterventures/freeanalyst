## 判定规则

```
达标   → 进入尽调
一项不达标但可解释 → 标记，需合伙人确认
两项及以上不达标 → 直接放弃
```

**注意**：阈值是筛子，不是判决。agent 应该做的是**精确报出哪条不达标、
差多少、材料里的原文是什么**，而不是替你做取舍。
