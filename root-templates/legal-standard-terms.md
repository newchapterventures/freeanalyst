# 标准条款立场

> 用来判断标的合同里哪些条款偏离了市场惯例。
>
> **填写要求：每条都要写"我们的底线"和"可以谈的区间"两栏。**
> agent 拿这个去比对合同，输出"偏离"还是"在可接受范围内"。

## 对赌与回购

| 条款 | 我们的底线 | 可谈区间 | 注意 |
|---|---|---|---|
| 业绩承诺指标 | | | 扣非净利 / 收入 / EBITDA |
| 承诺期长度 | | | |
| 补偿方式 | | | 现金 / 股份 |
| **回购义务人** | | | 实控人个人 / 公司 / 有限 or 无限连带 |
| 回购触发条件 | | | 时间 / 业绩 / 重大违约 |
| 回购利率 | | | 单利 / 复利 |
| 回购责任上限 | | | |

> **关注点**：回购义务人写"实控人个人无限连带"看起来对投资方最强，
> 但要区分**协议里写的**和**谈判中锁定的**。
> 如果访谈纪要里实控人对"无限"有保留，这条就还没落地。

## 用法

agent 读合同时，对每一条输出：

```
条款：回购义务人
合同原文：「……实控人xxx承担无限连带回购责任……」
来源：投资协议草案 第 8.2 条
比对：与 legal-standard-terms.md 的一致
偏离：无 / 有，具体在哪
风险：……
```

**必须带原文引用和条款编号。** 没有引用的判断一律不算数。
