# 尽调清单

> 按阶段和行业筛选。不是所有项都适用，但**漏项要能被发现**。

## 通用（所有阶段）

### 法律

- [ ] 主体资格与历史沿革
- [ ] 股东协议与公司章程
- [ ] 知识产权归属（尤其创始人在前雇主的成果）
- [ ] 重大诉讼与仲裁
- [ ] 行政处罚与合规记录
- [ ] 数据合规（个人信息、跨境）

### 财务

- [ ] 三年审计报告
- [ ] 管理报表与审计报告差异
- [ ] 收入确认政策
- [ ] 关联交易
- [ ] 表外负债与担保
- [ ] **QoE（盈利质量）**：一次性项目、口径调整是否合理

### 业务

- [ ] 前十大客户明细与合同
- [ ] 前十大供应商
- [ ] 定价机制与调价条款
- [ ] 订单/在手合同

### 人事

- [ ] 核心人员劳动与竞业协议
- [ ] 社保公积金缴纳完整度
- [ ] 股权激励安排

### 税务

- [ ] 税收优惠资格与期限
- [ ] 历史税务瑕疵
- [ ] 股权转让的税务处理

## 按阶段追加

### 早期 / 成长

- [ ] 单位经济模型
- [ ] 留存与复购
- [ ] 技术壁垒可验证性

### 成熟 / Pre-IPO

- [ ] 审计就绪度
- [ ] 内控有效性
- [ ] 上市合规差距清单
